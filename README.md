# 🐛 AI-Powered Bug Tracker

A full-stack bug tracking application with AI integration for automatic bug analysis and fix suggestions.

## 🌐 Live Demo
[https://ai-bug-tracker-e2qx.vercel.app](https://ai-bug-tracker-e2qx.vercel.app)

## 🚀 Features
- **Authentication** — JWT-based login/register system
- **Projects & Teams** — Create projects and invite team members
- **Bug Management** — Create, assign, and track bugs
- **AI Analysis** — Auto summary, severity prediction, and tags using Gemini AI
- **AI Fix Suggestions** — Get step-by-step fix suggestions with code hints

## 🛠️ Tech Stack
- **Frontend** — React.js, React Router, Axios
- **Backend** — Node.js, Express.js
- **Database** — MongoDB Atlas, Mongoose
- **Authentication** — JWT, bcryptjs
- **AI** — Google Gemini API
